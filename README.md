# C++ and Data Structures Coursework

A fork of [abhishek18124/PPCPPFTMay2025](https://github.com/abhishek18124/PPCPPFTMay2025), organised by lecture for studying C++ programming and data structures. The collection is coursework/reference material; it is not presented as an independently authored product.

## Topics

The lecture folders progress through basic syntax, loops and patterns, arrays and strings, recursion, pointers, object-oriented programming, linked lists, stacks and queues, trees and BSTs, heaps, hash maps, sliding windows, tries, dynamic programming, graphs and disjoint-set union.

## Run an example

Install a C++ compiler such as GCC or Clang. From the repository root:

```sh
c++ -std=c++17 'Lecture 03/001HelloWorld.cpp' -o /tmp/cpp-example
/tmp/cpp-example
```

Compile one example at a time: many files contain their own `main` function. Some lecture files are deliberately incomplete or illustrate language errors, and some problem solutions target online-judge harnesses instead of a standalone executable. This is not one combined application or a uniformly tested library.
